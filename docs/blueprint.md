# **App Name**: SimpliShop

## Core Features:

- Product Showcase: Display a catalog of products with their images, descriptions, and prices.
- Shopping Cart: Implement a shopping cart functionality allowing users to add and remove products. Show a running total of items in the cart.
- Order Total Display: Display the total price of the items in the cart in a clear and prominent location on the page.

## Style Guidelines:

- Primary color: White (#FFFFFF) for a clean and modern look.
- Secondary color: Light gray (#F2F2F2) for backgrounds and subtle accents.
- Accent: Teal (#008080) for interactive elements and calls to action.
- Use a grid-based layout for product listings to ensure a visually appealing and organized display.
- Ensure a clean and intuitive navigation for easy browsing.
- Use clear and consistent icons for common actions such as 'Add to Cart,' 'View Details,' and 'Checkout.'
